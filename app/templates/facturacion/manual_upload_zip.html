Cargar facturas desde un .zip — {{ 'BRMS' if issuer == 'BRMS' else 'Harraso Transport' }}

↺ Prefiero subirlas de una en una

Sube un único archivo .zip con el PDF y el XML de cada factura que ya emitiste desde el portal de SUNAT. Harris arma sola cada factura (cliente, monto, fecha, serie-número) leyendo el XML — no hace falta ningún Excel ni escribir nada a mano.

Para que Harris reconozca qué PDF va con qué XML, ambos archivos de una misma factura deben llamarse igual dentro del zip (solo cambia la extensión), por ejemplo:

  • F001-00123.pdf y F001-00123.xml
  • F001-00124.pdf y F001-00124.xml

Si a alguna factura le falta el PDF o el XML dentro del zip, esa factura no se carga — se sube individual desde "Cargar factura ya emitida". Si el cliente del XML no existe todavía en Harris, se crea automáticamente con el nombre y RUC del comprobante.

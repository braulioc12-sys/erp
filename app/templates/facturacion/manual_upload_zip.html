Cargar facturas desde un .zip — {{ 'BRMS' if issuer == 'BRMS' else 'Harraso Transport' }}

↺ Prefiero subirlas de una en una

Sube un único archivo .zip con el PDF y el XML de cada factura que ya emitiste desde el portal de SUNAT. Harris arma sola cada factura (cliente, monto, fecha, serie-número) leyendo el XML — no hace falta ningún Excel ni escribir nada a mano.

El PDF y el XML de una misma factura NO necesitan llamarse igual — Harris los relaciona leyendo el texto del PDF y buscando ahí la serie-número que trae el XML, sin importar el nombre del archivo. Puedes meter todos los PDF y todos los XML sueltos dentro del zip (o incluso otros .zip ya descargados de SUNAT, uno por factura — Harris también los abre solo).

Si a alguna factura le falta el PDF o el XML dentro del zip, o Harris no logra encontrar el PDF que corresponde a un XML, esa factura no se carga — se sube individual desde "Cargar factura ya emitida". Si el cliente del XML no existe todavía en Harris, se crea automáticamente con el nombre y RUC del comprobante.
